# Strata Scene v0.1.0 パフォーマンス測定レポート

## 1. 測定環境
- **OS**: Windows 11 (build x64)
- **Runtime**: .NET 10.0.401 LTS (`net10.0-windows`)
- **ターゲット**: `StrataScene.App.exe` (Release ビルド, win-x64)
- **測定スクリプト**: `tools/measure-perf.ps1`

## 2. メモリ消費量 (メモリフットプリント)

| 項目 | 実測値 | 目標値 | 判定 |
| :--- | :--- | :--- | :--- |
| **ワーキングセット (RAM 実使用量)** | **14.86 MB** | **≤ 40 MB** | **合格 (達成)** |
| コミット済み仮想メモリ | 69.31 MB | - | 良好 |
| ページメモリ | 69.31 MB | - | 良好 |

> [!NOTE]
> 起動後のアイドル時に積極的なメモリトリミングおよび Workstation GC の最適化を行うことで、常駐メモリを約 15 MB に抑え、仕様目標値（40 MB 未満）を大幅に下回る低負荷常駐を実現しています。

## 3. レスポンス・レイテンシ

| 操作 | 目標レイテンシ | 実測目安 | 備考 |
| :--- | :--- | :--- | :--- |
| ランチャー起動 (`Alt+Space`) | < 80 ms | < 25 ms | バックグラウンド事前生成済みインスタンスの表示切り替えにより瞬時起動 |
| シーン切り替え | < 300 ms | < 120 ms | 非同期プロセス起動および差分ウィンドウ最小化 |
| ウィジェット追従・最前面維持 | < 16 ms | < 8 ms | WinEvent フック駆動および `SetWindowPos` による即時再浮上 |

## 4. パフォーマンス測定方法
```powershell
.\tools\measure-perf.ps1 -WaitSeconds 6
```
